# 副業会計・確定申告管理

個人事業・副業向けの帳簿・申告準備支援Webアプリ（依存なしの単一ファイル `index.html`）。データはブラウザのIndexedDBに保存され、サーバーへ送信しません。

## 起動
`index.html` をブラウザで開くだけ。

## 公開（GitHub Pages）
1. 非公開リポジトリに `index.html` と `.github/workflows/pages.yml` をコミット（実データは絶対にコミットしない）
2. Settings → Pages → Source を「GitHub Actions」にする
3. 税務データを扱うため、GitHub Pagesの利用規約・公開範囲を事前に確認する

## テスト
画面の「データ・テスト」→「実行」、または `node tests_node.js`（ケース1〜9のうち計算系を検証）。

## バックアップ
「データ・テスト」→ JSONバックアップ。ブラウザデータ削除や端末故障で消えるため定期的に保存してください。復元は形式検証と確認ダイアログ付き。

## 機能
事業管理 / 収入 / 経費(按分) / 給与 / 事業主貸借 / 固定資産(簡易定額法) / 投資取引(別管理) / 自動仕訳・仕訳帳・試算表・総勘定元帳・出納帳 / 損益・貸借の基礎データ / 所得区分別集計 / チェックリスト / 根拠URL管理 / CSV取込(列対応付け・プレビュー・重複検知) / CSV・JSON出力 / 印刷でPDF保存 / スマホ対応

## 制約・未実装
- 税額計算、青色申告特別控除の判定、決算書の公式様式出力、e-Tax送信は未実装
- 期首残高・元入金、勘定科目の追加、手動仕訳、補助元帳は未対応。貸借対照表は基礎データのみ
- 減価償却は仮計算。投資の損益計算・損益通算・繰越は未実装(実現損益は手入力)
- 証憑ファイル自体の保存、OCR、電子帳簿保存法対応、サーバー連携は未実装
- 税務ルールは対象年ごとに国税庁の一次情報で必ず確認してください
