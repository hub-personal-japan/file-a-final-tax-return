# 副業会計・確定申告管理

個人事業・副業向けの帳簿・申告準備支援Webアプリ（依存なしの単一ファイル `index.html`）。データはブラウザのIndexedDBに保存され、サーバーへ送信しません。

## 起動
`index.html` をブラウザで開くだけ。

## 公開（GitHub Pages）
1. 非公開リポジトリに `index.html` と `.github/workflows/pages.yml` をコミット（実データは絶対にコミットしない）
2. Settings → Pages → Source を「GitHub Actions」にする
3. 税務データを扱うため、GitHub Pagesの利用規約・公開範囲を事前に確認する

## テスト
画面の「データ・テスト」→「実行」、または `node tests_node.js`（ケース1〜9のうち計算系を検証）。

## バックアップ
「データ・テスト」→ JSONバックアップ。ブラウザデータ削除や端末故障で消えるため定期的に保存してください。復元は形式検証と確認ダイアログ付き。

## 機能
事業管理 / 収入 / 経費(按分) / 給与 / 事業主貸借 / 固定資産(簡易定額法) / 投資取引(別管理) / 自動仕訳・仕訳帳・試算表・総勘定元帳・出納帳 / 損益・貸借の基礎データ / 所得区分別集計 / チェックリスト / 根拠URL管理 / CSV取込(列対応付け・プレビュー・重複検知) / CSV・JSON出力 / 印刷でPDF保存 / スマホ対応(横スクロールなし) / 勘定科目の追加・期首残高・手動仕訳・事業別補助元帳 / はじめにガイド・サンプルデータ・各画面の説明

## 制約・未実装
- 税額計算、青色申告特別控除の判定、決算書の公式様式出力、e-Tax送信は未実装
- 貸借対照表は基礎データのみ(公式様式ではない)。買掛金の専用管理、自動仕訳の個別編集は未対応
- 減価償却は仮計算。投資の損益計算・損益通算・繰越は未実装(実現損益は手入力)
- 証憑ファイル自体の保存、OCR、電子帳簿保存法対応、サーバー連携は未実装
- 税務ルールは対象年ごとに国税庁の一次情報で必ず確認してください

## 主な仕様(会計ロジック)
- 売上計上(売掛金)と入金(消込)は別仕訳。入金日が空欄なら売掛金として残る
- 経費の支払方法: 銀行 / 現金 / カード(利用日に未払金→引落日に消込) / 未払金 / 個人資金の立替(事業主借)
- 前年末残高は翌年へ自動繰越(期首残高の手入力は最初の年のみ)
- 本業の給与は月別入力・副業とは別枠。副業の申告要否の目安は国税庁タックスアンサーNo.1900に基づく簡易判定
- CSVは「対象年のみ」「全年度」「マスター全件」をボタンで区別。JSON復元は型・日付・金額・ID重複・参照整合性を検証
- 印刷/PDFは申告準備資料であり、税務署への提出書類ではありません
- 固定資産は取得時の支払方法・事業使用割合(私用分は事業主貸)・資産区分の科目を反映。償却は仮計算、売却・廃棄・少額特例は未実装
- CSV取込: 負数(返金・取消)は自動取込せず、カード引落との重複候補を検出
- 事業・勘定科目は使用中の場合は削除不可(事業は「無効」に)
- 固定資産の減価償却: 定額法(平成19年4月1日以後取得・耐用年数2〜16年)のみ国税庁の償却率表で自動計算(端数処理は未確認)。それ以外・売却/廃棄年以降は自動計算せず「要確認」に表示
- 源泉徴収税額: 売上は源泉徴収前の総額で計上し、源泉は経費にせず事業主貸で処理(科目は未確認)。売上計上年と入金年が異なる取引・率が10.21%と異なる取引は「要確認」
- 手動仕訳の損益科目は事業別集計にも含む(事業未指定は「(未設定)」)
- 少額減価償却資産の特例(令和8年度改正を含む)は一次情報未確認のため未実装
