# 副業会計・確定申告管理

会社員の本業(給与)と複数の副業・投資を一元管理し、帳簿(仕訳・試算表・元帳)と申告準備資料を作る個人用Webアプリです。依存ライブラリなしの単一ファイル `index.html`。データはブラウザのIndexedDBにのみ保存され、サーバーへ送信しません。

> **本アプリは公式の確定申告書・税務ソフトではありません。** 出力(印刷/PDF・CSV)は申告書作成のための参考資料で、税務署への提出書類ではありません。提出には国税庁の公式様式または確定申告書等作成コーナーを使用してください。税務上の最終判断は国税庁の案内・税務署・税理士で確認してください。

## 起動・公開・テスト
- 起動: `index.html` をブラウザで開く
- 公開(GitHub Pages): リポジトリに `index.html` と `.github/workflows/pages.yml` を置き、Settings → Pages → Source を「GitHub Actions」に設定。実データ(収入・領収書・口座情報)は絶対にコミットしない。税務データを扱うため、GitHub Pagesの利用規約・公開範囲を事前に確認する
- 計算・仕訳・保存・復元のテスト: `node tests_node.js`(失敗があると終了コード1)
- ブラウザ実操作テスト: `python3 e2e_browser_test.py`(Playwright + Chromium が必要)

## 機能
事業・副業の自由な追加(並び替え可) / 収入(売上計上と入金を分離) / 経費(支払方法・按分) / 本業の給与(月別・副業とは別枠) / 事業主貸借 / 固定資産・減価償却(一部) / 投資取引(別管理) / 勘定科目の追加 / 期首残高 / 手動仕訳 / 仕訳帳・試算表・総勘定元帳・事業別補助元帳 / 損益・貸借の基礎データ / 申告要否の目安 / チェックリスト / 要確認の取引一覧 / CSV取込(列対応・プレビュー・重複候補) / CSV・JSON出力 / 印刷(申告準備資料) / スマホ対応

## 会計処理の仕様
- 売上計上日に「売掛金・手数料・事業主貸(源泉)/売上」、入金日に「普通預金/売掛金」を別々に仕訳。入金日が空欄、または状況が「未入金」の間は売掛金のまま
- 経費の支払方法: 銀行 / 現金 / カード(利用日に未払金、引落日に消込) / 未払金 / 個人資金の立替(事業主借)。私用分(按分外)は事業主貸。立替の私用分は記帳しない
- 前年末の資産・負債残高は翌年に自動繰越(収益・費用は繰り越さない)。期首残高の手入力は最初の年のみ有効
- 手動仕訳・カスタム勘定科目(費用/収益/資産/負債)。使用中の科目は削除・名称/種別変更不可
- 事業別集計は、収入の手数料・経費・固定資産の仮償却費・手動仕訳の損益科目を含み、帳簿の損益と一致(事業未指定は「(未設定)」)

## 減価償却(自動計算の範囲)
- 自動計算: 定額法・平成19年4月1日以後取得・耐用年数2〜16年。国税庁の償却率表の率(0.500〜0.063)を使い、年額=取得価額×償却率、初年度は使用開始月から12月までの月割、最終年は未償却残高1円まで。事業使用割合は償却額に乗じて算入
- **端数処理(切捨て等)の規則は一次情報で未確認**のため、金額は仮計算です
- 自動計算しない(「要確認」に表示): 耐用年数17年以上、平成19年3月以前取得、定率法、一括償却資産、少額減価償却資産の特例、10万円未満の処理
- **売却・廃棄は未実装**: 売却・廃棄日の入力は保存できません(誤った仕訳を作らないため)。個人の事業用資産の売却損益は事業所得ではなく譲渡所得になる場合があります(民間解説が国税庁No.3105/3152を根拠に記載。一次情報は未確認)。売却・廃棄した資産は「償却方法」を「償却停止」にし、売却処理は手動仕訳と税務署・税理士の確認で行ってください

## 源泉徴収の注意点
- 売上は源泉徴収前の総額で計上し、源泉徴収税額は経費にせず「事業主貸」で処理(勘定科目は国税庁が指定するものではなく、**科目の選択は未確認**)
- 源泉徴収の対象は報酬の種類で決まります(原稿料・デザイン料・講演料・弁護士等の報酬など)。YouTube広告収入・物販・多くの開発請負などは対象外の場合があります
- 売上計上年と入金年が異なる取引、率が10.21%と大きく異なる取引は「要確認」に表示します(**どの年分に帰属するかは一次情報で未確認**)

## データの保存・バックアップ
- 保存先はブラウザのIndexedDB(端末・ブラウザごと)。ブラウザデータの削除・端末故障・プライベートブラウズで失われます。「データ・テスト」から定期的にJSONバックアップを保存してください
- 保存に失敗した場合は成功表示を出さず、画面のデータも元に戻します(登録・編集・削除・取込・復元・全データ削除)。保存領域を読み込めない場合は、既存データの上書きを防ぐため保存を停止します
- JSON復元は、型・必須項目・日付・金額・事業使用割合・ID形式と重複・事業ID・勘定科目の参照を検証してから、保存に成功した場合のみ反映します(失敗時は元のデータを保持)。旧バージョンのバックアップは不足項目を補完します
- CSV出力は「対象年のみ/全年度/マスター全件」を画面で区別しています

## 国税庁の一次情報(確認日 2026-10-15)
- 給与所得者の確定申告が必要な場合(副業の申告要否の目安): タックスアンサー No.1900 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900.htm / Q&A https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900_qa.htm
- 源泉徴収: タックスアンサー No.2793 / 2795 / 2798(https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2795.htm ほか)、No.6929(消費税込みの扱い)、源泉徴収のあらまし
- 減価償却: 減価償却資産の償却率表(https://www.nta.go.jp/law/joho-zeikaishaku/shotoku/shinkoku/070914/pdf/01.pdf ほか)、タックスアンサー No.2106 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2106.htm
- **未確認(実装していません)**: 少額減価償却資産の特例のうち令和8年度改正(40万円未満・適用期限延長)。国税庁の一次情報で成立・施行・適用開始を確認できておらず、民間解説のみです。国税庁No.2100の30万円未満(令和8年3月31日まで)の内容は確認済みですが、実装していません
- 住民税の扱いは自治体の案内を確認してください
